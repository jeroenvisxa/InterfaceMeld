# InterfaceMeld

Syncs multiple desktop and mobile application windows into a unified, customizable workspace for software developers.

With InterfaceMeld, you get a lightweight tool that stays out of your way.

**What you get**

- Syncs multiple desktop and mobile
- application windows into a unified,
- customizable workspace for software developers

## Key Features

- Syncs multiple desktop and mobile
- application windows into a unified,
- customizable workspace for software developers

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/InterfaceMeld.git`
2. `cd InterfaceMeld`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure InterfaceMeld, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
